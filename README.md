# Capan — Премиальная бургерная

Capan — современный адаптивный сайт премиальной бургерной.

## Как запустить

1. Скачать репозиторий.
2. Открыть файл `index.html` в браузере.

## Инструменты

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- Google Fonts

## Возможности

- Адаптивный дизайн
- Анимации
- Фильтрация меню
- Интерактивная корзина
- 3D Tilt эффект
- Мобильное меню
